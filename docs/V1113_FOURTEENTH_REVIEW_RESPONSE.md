## 四项实施取舍与代价

1. **只对齐已记录证据。** 已知动作、完整对照指纹、匹配身份及有效结果时间才生成操作说明，不补null或归档类别。代价：旧事件可以明确记录了某操作，但仍没有可比较的前后状态变化。
2. **处理规则与业务计数分开。** 只对已验证附件操作分类policy，两侧文字均保留阶段。代价：不认识或不匹配的载荷仍按通用事实计数，数字可能多于业务结果数量。
3. **载荷覆盖不等于状态完整。** 所有阶段覆盖标记改用载荷/已记录字段措辞。代价：阶段表头发生变化，完整中文快照入口名称保留。
4. **一处定义编辑字段。** 表单和写入边界共用注册表，不支持的对象明确拒绝。代价：扩展新的明细族需要注册实际可编辑字段及对应业务能力。
