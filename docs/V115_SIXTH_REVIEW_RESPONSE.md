## 明确采用的业务规则

- 停用路由暂停工厂证据写入及接单，仍保留历史读取和拒单。它不是收回全部历史权限；源店管理人仍可治理误传，系统超级管理员仍有原有例外。
- 改派归档与人工停止共享分开显示，但两者都不自动恢复共享；已下载或已开始传输的副本无法远程收回。
- 移除行可改变拟额计算基线，不代表批准新基线；旧order_version必须经编辑确认，随后由其他管理人员审批。仍有失效行时，保留移除进度并禁止批准。
- 不新增仅登记折扣口径模式，按全部产品重算、历史金额差异和完整补录的人工核对要求保持。

## 文件清理操作边界

1. 停止共享/改派只归档，按源订单读取范围保留证据，文件不会自动物理删除。
2. 确需删除他人交接证据时，由系统超级管理员核对企业留存要求，经现有应用删除动作授权；普通源店长不能代删，归档后的仅工厂身份上传者也不能删除。
3. 应用删除先保存deleted_at、哈希与审计，事务提交后尝试物理清理。失败时运维可运行 `python manage.py purge_attachments` 重试；该命令不授予删除权，也不会清理仅归档文件。
4. 数据库/media备份、外部下载副本及备份保留周期由运维按企业政策另行处理。本系统命令不证明这些副本已经清理。本轮没有删除历史归档或修改备份副本。
