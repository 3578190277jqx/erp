# ERP v1.1 implementation plan

> Execute in the current session with superpowers:executing-plans and test-driven-development; independent final review required.

**Goal:** Upgrade the existing full-chain ERP using the verified review and official market references.
**Architecture:** Keep Django monolith, add focused pricing/collaboration/material/receivables services and dedicated feature views/partials. Preserve existing history, role isolation, CAS and audits.
**Tech Stack:** Existing Django 5.2 LTS and Tabler stack, SQLite local, PostgreSQL CI.
**Spec:** `docs/superpowers/specs/2026-10-16-erp-v11-design.md`

## Global constraints

Chinese UI, Decimal HALF_UP, no public media URLs, no cross-org arbitrary links, all writes scoped and atomic. Existing data and user-created `.workbuddy/` files must be preserved. New features must be usable in UI and tested beyond service-only code.

## Review focus

- Historical orders remain numerically unchanged and snapshots cannot mutate source quotes.
- Factory users cannot infer retail prices, customer contacts or arbitrary source data.
- Attachment downloads validate the parent scope even after assignment changes.
- Reserving, issuing and receiving cannot overcommit or double-post quantities.
- Receivable plans, existing payments and order changes cannot silently diverge.
