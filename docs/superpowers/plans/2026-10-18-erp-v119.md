## Decisions

Do not replace them with a dictionary under attachment. Cost: modest extra audit payload size, avoided in rendered duplicate panels where fully identical.

Ruling: Display valid aware timestamp values in configured local timezone with explicit UTC offset; preserve raw JSON including microseconds. Naive/invalid values are not assigned a guessed timezone. Cost: display precision is seconds; raw evidence retains original precision.
