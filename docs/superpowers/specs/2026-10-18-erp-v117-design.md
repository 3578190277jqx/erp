## Decisions

1. X1: audit timeline links use the same active-organization scope as their destination. Hide unreachable links; do not widen audit authorization or auto-switch organization.
2. X2: Handoff upload requires sent/accepted/completed, for source and factory alike, including superusers. Rejected/withdrawn require explicit resend first. Historical reads and scoped emergency stop remain; completed may accept completion photos. Pause override does not override lifecycle status.
3. X8: retain the existing superuser route override and record route_override=true when the real source/target route is absent/disabled. Determine this inside the upload transaction from the actual route, not route_enabled(user), which deliberately short-circuits for superuser. User POST cannot set audit data.
4. X3/X4: audit detail leads with field-level before/after differences; full translated snapshots and original JSON remain expandable. Recursively label known snapshot fields using model metadata, retain IDs with safely scoped current reference names, and explicitly label current-name resolution as not historical. Never look up arbitrary models from payload strings or expose inaccessible FK names. Empty text/null/absent fields are explicit; false/zero remain meaningful. Do not rewrite stored audit records.
5. X5: direct unauthorized detail remains404; the attachment panel's mid-render loss of permission shows an unavailable message instead of empty-content copy. Stale version remains a refresh state. Hide empty-state/upload on either failure.
6. X6: remove unused wrappers after updating their one test caller. Keep the two epoch reads: they bracket metadata/permissions and detect concurrent evidence mutation. Passing the first epoch to the final comparison would defeat the safety check. Add a direct interleaving regression to prove this.
7. X7: add nullable EvidenceState.updated_at. Old states remain unknown (null); future epoch increments set the timestamp atomically with CAS. Superuser-only read-only admin listing/detail shows organization/module/object/epoch/time. No admin add/change/delete actions; no broad grant to staff.
